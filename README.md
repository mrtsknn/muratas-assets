# muratas-assets

Murat AŞ uygulamalarının herkese açık marka görselleri ve yasal metinleri (app config içinden https ile referans verilir).

- `ingilizce-a1/`: ikon, adaptive foreground, logo, splash, KVKK aydınlatma metni.
- `ales/`: ikon, adaptive foreground, splash (PNG + SVG kaynakları, core-learning `mobile/assets/ales`'ten), logo (`render-ales.mjs`).
- Görseller `render.mjs` ile üretilir: `npm i && node render.mjs`.
